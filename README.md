# MUNDO-SENAI
MUNDO-SENAI é um código baseado em uma votação de cursos, usado para que você e várias outras pessoas possam votar em seu curso favorito e ao final do tempo de votação ver qual curso foi o ganhador. Ele foi feito com o propósito de ser apresentado no Mundo Senai de 2026 e foi feito por alunas do Curso de Desenvolvimento de Sistemas de Indaial.
